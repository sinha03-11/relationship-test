# ❤️ HeartSync | Relationship Quality Insights

HeartSync is a professional, interactive web application designed to help individuals reflect on the health and depth of their relationships. 

## ✨ Features
* **20 Curated Questions:** Focuses on effort, understanding, and emotional safety.
* **Responsive Design:** Optimized for both mobile (iOS/Android) and desktop browsers.
* **Real-time Analysis:** Generates a quality percentage and professional summary instantly.
* **Glassmorphism UI:** Built with Tailwind CSS for a modern, high-end aesthetic.

## 🚀 How to Use
1.  Open the website.
2.  Answer the 20 questions honestly (Yes/No).
3.  Review your relationship quality score and analysis.
4.  Use the "Share" button to copy your result link.

## 🛠️ Technology Stack
* **HTML5** - Structure
* **Tailwind CSS** - Styling & Responsiveness
* **Vanilla JavaScript** - Logic & Score Calculation
